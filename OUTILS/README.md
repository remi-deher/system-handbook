# Outils communs

Outils réutilisables dans plusieurs portées du dépôt, avec leurs prérequis et limites de plateforme.

- [Git](GIT/README.md) : nettoyage des branches et worktrees locaux déjà validés et poussés.
- [Chiffrement](CHIFFREMENT/README.md) : commandes natives age/tar pour protéger et récupérer des fichiers ou dossiers à noms opaques, sous Linux et Windows.
- [Claude Code](CLAUDE-CODE/README.md) : comportements de Claude Code communs à tous les systèmes, comme les sessions Remote Control masquées de `/resume`.
- [EasyEffects](EASYEFFECTS/README.md) : autoload d'un preset par sortie audio, presets de référence et méthode de mesure Waves du portable Dell.

Les contrôles du dépôt sont séparés dans [.github/scripts](../.github/scripts/README.md). Les scripts spécifiques à une portée restent dans son `05-SCRIPT/`. Voir les [instructions IA](AGENTS.md) et [l’index général](../README.md).
