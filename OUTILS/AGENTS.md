# Instructions pour les IA — Outils communs

Lire `../AGENTS.md`, puis `README.md` ici.

Ce dossier contient les outils partagés par tout le dépôt. Ce n’est ni une distribution ni une portée OS : ne pas y reproduire les neuf rubriques. Chaque module utilise des guides standard `AGENTS.md` et `README.md`, précise son usage et ses plateformes réellement testées, et documente les validations adaptées. Privilégier les commandes natives et outils maintenus plutôt qu’un script maison lorsqu’ils satisfont le besoin.

Les contrôles CI restent dans `.github/`. Ne pas dupliquer un outil dans les branches OS ; le référencer. Ne pas ajouter de fournisseur de clés ni de référence d’accès privée dans les modules.
