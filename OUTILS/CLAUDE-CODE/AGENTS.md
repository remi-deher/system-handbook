# Instructions pour les IA — Outils Claude Code

Lire `../../AGENTS.md`, `../AGENTS.md` et `README.md`.

Ce dossier regroupe les comportements de Claude Code qui ne dépendent pas du système d'exploitation. Ce qui dépend de l'OS (service systemd, chemins propres à une distribution, scripts) reste dans la portée concernée, par exemple `OS/Linux/arch/04-LOGICIEL/claude-code/`.

Préciser la version de Claude Code testée : le comportement peut changer d'une version à l'autre. Ne jamais copier ici un identifiant de session, d'environnement ou de compte, un nom de machine ou un chemin personnel : utiliser des marqueurs comme `<IDENTIFIANT>` et `~`.
