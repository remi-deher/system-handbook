# Campagne des effets isolés

MaxxBass, Détails et Largeur mesurés séparément à 25, 50, 75 et 100 %. Voir la [méthode](METHODE.md) et le [rapport](RAPPORT-EFFETS-ISOLES.md). Scripts : `campaign.py`, `run_campaign.py`, `run_extra_volumes.py`, `run_volume_controls.py`, `acquisition.py`, `analyze_campaign.py`, `summarize_campaign.py`, `plot_campaign.py`, `write_report.py`, `finalize_campaign.py`. Les `plan*.json` décrivent le programme prévu ; seul le manifeste final (non conservé) atteste ce qui a été achevé.

Voir les [instructions IA](AGENTS.md) et [l'index Mesures Waves](../README.md).
